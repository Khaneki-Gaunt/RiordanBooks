# RiordanBooks
> *"No mires atrás, sigue leyendo."*

¡Bienvenidos, semidioses! Esta es la aplicación oficial de lectura para nuestra comunidad Club Campamento Mestizo. Aquí podrás descargar el instalador para acceder a todos los libros e historias del universo de Rick Riordan.

## 📦 Descarga e Instalación

Para obtener la aplicación, no necesitas ir al Inframundo. Solo sigue estos pasos:

1. Ve a la sección de **[Releases (Lanzamientos)](../../releases)** a la derecha (o arriba en móviles).
2. Busca la versión más reciente (ej. v1.0.0).
3. En la sección "Assets", haz clic en el archivo **`LectorMestizo_Setup.exe`** (o el nombre de tu archivo) para descargarlo.
4. Ejecuta el archivo e instálalo en tu dispositivo.

## ✨ Características

* 🏛️ **Interfaz del Olimpo:** Diseño inspirado en el campamento mestizo.
* ⚡ **Modo Lectura Rápida:** Para los que tienen TDAH (como todo buen semidiós).
